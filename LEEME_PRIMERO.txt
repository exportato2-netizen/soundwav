SOUNDWAV - VERSION 1.3
======================

USO RAPIDO
----------
1. Descomprime todos los archivos en una carpeta.
2. Haz doble clic en launcher.bat.
3. Si falta Python compatible, el launcher intentara instalarlo automaticamente.
4. Se abrira la interfaz en el navegador.
5. Pega una URL publica de SoundCloud y pulsa Descargar.

SALIDA
------
Los WAV finales quedan en:
%USERPROFILE%\Music\WAV_Descargas

El historial y registro interno quedan en:
%LOCALAPPDATA%\soundwav

LIMPIEZA DE METADATOS
---------------------
La version 1.3 obliga a que app.py cargue la capa de limpieza segura.

El archivo fuente se descarga primero a una carpeta temporal interna. FFmpeg lo
convierte a PCM y luego la aplicacion reconstruye el WAV final conservando solo:
- fmt
- data

Por tanto, el WAV final no conserva tags heredados, LIST/INFO, BEXT, iXML,
caratulas, capitulos, URL, comentarios, IDs del extractor ni identificadores del
software de conversion.

El nombre final tampoco incluye el ID de SoundCloud. Ejemplo:
001 - Nombre de la pista.wav

IMPORTANTE
----------
La limpieza se refiere a metadatos y estructura del archivo. No puede quitar
informacion que forme parte del propio audio audible sin modificar ese audio.

ACTUALIZAR
----------
Ejecuta ACTUALIZAR.bat. Si todavia no existe el entorno .venv, el actualizador
lo prepara automaticamente con launcher.bat --setup-only y luego continua.

REQUISITOS
----------
- Windows 10 u 11
- Conexion a Internet
- Python 3.11 o superior; el launcher intenta instalar Python 3.14 si hace falta

USO RESPONSABLE
---------------
Utilizalo solo con contenido propio, con permiso del titular o cuando la
legislacion aplicable permita la descarga. No evade cuentas privadas, DRM ni
controles de acceso.
